# תאוריה מדברת

אפליקציה ללימוד תאוריה לנהיגה, בעברית, ערבית, רוסית ואנגלית.
קובץ אחד (`index.html`), service worker משלה (`sw.js`), בלי build ובלי תלויות.

## היא מוגשת מתוך bekol.co.il — וזה לא פרט טכני

הריפו הזה מתפרסם ב-GitHub Pages תחת הדומיין של האתר הראשי:
`https://bekol.co.il/` + שם הריפו. האתר הראשי הוא הריפו
`lagstein1-png/lagstein1-png.github.io`, ושניהם חולקים מקור אחד.

לכן `index.html` טוען בנתיבים מוחלטים ארבעה קבצים **שאינם בריפו הזה**:

| קובץ | מה הוא |
|---|---|
| `/tutor/josh-face.js` | הפנים של ברק — תצוגה בלבד |
| `/tutor/josh-state.js` | גלאי מצב הלומד |
| `/tutor/josh-local.js` | המוח המקומי, כשהשרת אינו זמין |
| `/tutor/tutor.js` | הפאנל של ״עזרה מהמורה״ (ברק) |

ארבעתם יושבים בתיקייה `tutor/` של הריפו הראשי.

## מה קורה כשמגישים אותה לבד

שרת מקומי, Netlify, דומיין אחר — כל מקום שאין בו את `/tutor/`
של האתר הראשי:

- ארבעת הקבצים מחזירים 404.
- **האפליקציה ממשיכה לעבוד** — שאלות, הקראה, מבחן, אופליין. כל
  קריאה ל-`TUTOR` מוגנת ב-`window.TUTOR`, וכפתור ברק פשוט לא מופיע.
- בקונסול מופיעה אזהרה אחת שמתחילה ב-`[תאוריה מדברת] ברק כבוי`
  ומונה אילו קבצים חסרים. בלעדיה השבירה הייתה שקטה.

כדי לבדוק מקומית **עם** ברק — מגישים את שני הריפו מתיקייה אחת, כך
ש-`/tutor/` ותיקיית האפליקציה יושבים זה לצד זה, כמו באתר החי.

## אל תעתיקו את `/tutor/` לכאן

עותק שני יסתעף מהראשון בעדכון הבא, ואז יהיו שני ברק שמתנהגים אחרת.
המקור היחיד הוא הריפו הראשי.
